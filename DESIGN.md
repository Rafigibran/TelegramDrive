# Telegram Drive Android Design Direction

Status: DURING

## Direction

The Android interface uses a compact utility-first layout designed around file management rather than a generic dashboard shell.

- Flat surfaces with clear boundaries instead of glass or decorative blur.
- Charcoal application surfaces with the existing amber accent as the primary action color.
- Medium corner radii and restrained shadows.
- Navigation behaves like an Android utility surface, anchored to the screen edge instead of floating as a decorative card.
- Content density adapts to touch interaction without relying on oversized cards or excessive whitespace.
- Loading, empty, error, and disconnected states must communicate a concrete next action or current condition.
- Motion is limited to feedback and progress; no decorative looping animation is used for navigation or empty states.

## Scope

This direction applies to the Android/mobile experience first. Desktop layouts retain their existing product structure unless a later change explicitly targets them.

## Copy

Mobile UI copy stays direct and operational. Labels describe the action or state and avoid filler, marketing language, fabricated metrics, or unnecessary status decoration.
